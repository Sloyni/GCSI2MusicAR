PREMIERS ACCORDS

Un peu d’air.
Beaucoup de musique.

  1. Activez la caméra. Le mode Turbo utilise le GPU quand il est disponible. Gardez les doigts visibles et éclairés.
  2. Piano : touchez dans l’image. Une note démarre dès que le cercle d’un doigt entre sur une touche. Sortez du clavier pour l’arrêter. Aucun mouvement de frappe n’est nécessaire.
  3. Batterie : frappez vers le bas. Six pads ; levez puis redescendez le doigt pour répéter. La vitesse règle le volume. Le mode Contact reste disponible.
  4. Guitare : choisissez votre jeu. Accords : main à gauche pour choisir (1 Do, 2 Sol, 3 Lam, 4 Fa, 5 Rém), guitare attachée au poignet droit ; touchez les cordes avec un doigt pour jouer les notes une par une, ou traversez-les pour gratter. Mélodie : pincez le pouce avec les autres doigts. Cordes libres : frettes et cordes dans l’image.

Calibrez le piano et les pads en les déplaçant dans l’image. Activez le pitch pouce–index et centrez votre écart confortable. Les gestes fonctionnent à hauteur normale avec la main de contrôle : rapprocher/écarter les doigts règle la hauteur, balayer la main ouverte change le style. Souris et clavier restent disponibles. Échap coupe les voix actives.

Le piano propose Contact ou Frappe et des gammes guidées. Quitter une touche coupe sa note, même avec le sustain clavier. Les styles modifient le timbre et les effets sur les enregistrements locaux.
CONSTRUIT POUR EXPLORER

Le réel rencontre
le numérique.

Python capture la caméra et MediaPipe suit jusqu’à deux mains, avec 21 repères par main. Le piano est superposé à l’image ; les contacts des doigts sont analysés localement.

Le son est joué par Web Audio : enregistrements de piano et de guitare, polyphonie, dynamique, sustain et réverbération. La batterie utilise une synthèse de percussions.
